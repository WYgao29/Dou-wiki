# Web UI 设计系统（当前实现）

2026-10-21，Web 0.2.88，包 0.2.1。当前界面只支持桌面浏览器，最窄按约 960px 设计，不做手机或窄屏适配。窗口更窄时主容器保持 960px 最小宽度，页面可以横向滚动。界面支持阅读、完整逐字稿、本地视频链接、已有批次与任务管理、信息 / 灵感 / 专题来源和系统维护；新建业务请求由 MCP Agent 执行。收藏目录记录提示请 Agent 选择收藏夹并发起作品读取。聊天、模型配置、自动成果和新导入表单已删除。目标规格与实施记录见 [重设计方案](web-ui-redesign-readwise.md)。前半部分记录当前行为，带版本的验证段落保留历史基准；当前安装与验证见[项目审查修复记录](maintenance/2026-10-13-project-review-fixes.md)，独立 runtime 的安装约定见[精简审查修复记录](superpowers/reviews/2026-10-11-mcp-gateway-review-fixes.md)。

## 动效与输入方式

按 `emil-design-eng` 调整鼠标操作的动效。弹窗居中轻微位移与缩放；支持 `transition-behavior: allow-discrete` 的浏览器同时显示进出过渡，不支持时即时开合。原生关闭、表单提交和焦点恢复不等待动画。筛选和更多菜单从触发按钮位置展开，关闭时立即禁用交互并从辅助技术树隐藏，透明度与 transform 的退场可以被再次打开打断。提示沿同一方向进出，更新文字不重新播放入场；隐藏后的操作按钮不能接收焦点。

捕获输入方式：按键与辅助设备触发的点击即时更新界面，命令面板始终即时打开；键盘打开文章不调用封面视图过渡，引用定位不使用平滑滚动。鼠标点击专辑墙封面时保留短的视图过渡；初次加载与列表导航不增加入场动画。右侧覆盖面板只过渡 transform，不改变主栏宽度；桌面网格和左栏保持即时布局。动画不驱动宽、高、边距或模糊。系统“减少动态效果”设置关闭位置动画和按压缩放，加载进度仍使用原有状态逻辑。

## 资料库

信息面板底部操作统一为 32px 高、13px / 16px 文字和 16px 图标，按钮与链接采用相同的垂直居中布局。

首次打开默认列表；UI 偏好版本迁移到 `3` 时重置旧视图，之后记忆用户选择，URL 的 `view=gallery` 优先。资料行高 88px、封面 48×64px。标题和摘要各单行省略，元信息保留来源、博主、类型、日期、灵感和最多两个标签。

侧栏「灵感」仍按文章归组，列表与专辑墙展示用户保存的灵感原文，替代普通文章摘要；同一文章的多条灵感逐条展示，每条最多预览三行，保留原有换行并提供完整文字提示。列表行随内容增加高度，标题、来源和灵感数量继续保留。其他资料视图继续使用原有摘要规则。

排序控件按完整选项文字确定宽度，不截断「发布时间：从新到旧」等长选项。排序、列表与专辑墙图标统一为 16px；排序使用并列的上下箭头，列表使用三行分隔，专辑墙使用四格布局。

来源 Tabs 提供全部 / 视频 / 图文，并写入 URL。筛选面板宽 320px，提供博主、内容类型和「仅显示有灵感的文章」；博主超过 8 位时提供搜索，博主和内容类型使用多选框。最近加入按过去 7 天的采集时间筛选；侧栏显示全库数量，任务数量与待办条使用同一个 overview 结果；待办条为 13px，左侧 6px accent 圆点，右侧文字链接。

焦点行使用墨绿竖条，右栏同步封面、摘要、日期、标签、灵感与媒体状态；行 hover 或包含焦点时显示收藏和更多菜单。只读 Markdown 可以阅读和筛选，不能收藏、删除、重新分析或作为专题来源。专题页的「从资料库选择来源」进入完整资料库并开启多选，清除之前的分类、搜索及筛选；资料库工具栏的「选择」保留当前筛选。专题选择支持跨筛选，提交全部已选来源。

专辑墙使用 3:4 封面、160px 最小列宽和 24px 间距，保留收藏角标，取消入场动画和缩放。列表支持 `j/k/↑/↓`、`Home/End`、`Enter/o`、`f` 收藏、`x` 选择、`v` 切换视图、`Shift+F` 筛选；专辑墙方向键按网格移动。

## 标签

左侧栏不列标签名称、数量或「全部标签」，只在「工作」中保留「标签」入口，进入 `/tags` 管理页。文章和右侧信息面板显示完整标签，紧凑资料行最多显示两个；第三个标签仍可在文章与信息面板中查看。筛选面板不再列出标签；可从标签管理页、文章或信息面板中的标签进入对应资料列表。

新分析的标签只描述本篇中心内容，不接收 `existing_tags`，不优先复用或向近似分类靠拢。通常两个，最多三个；中心不足可以少写或为空。第一个是作品最具体的中心对象，第二个是所讨论的问题、方法或判断，第三个只用于另一个同等中心。中心对象可以是专名，顺带提到的产品、类比和例子不入标签，也不使用宽泛背景词凑数。Gateway 使用 `analysis_rules.py`，提示词版本为 `v2.4-content-tags`。

新分析提交时去首尾空白、丢弃空标签、按原顺序去重，仍超过三个就拒绝，不截断。存储模型不设数量上限，已有文章不自动改标签，旧数据仍可阅读和索引。用户已确认的合并别名继续在最终落库时解析。

管理页使用「全部标签 / 可能重复 / 别名」三个页签，默认展示全部标签，辅助记录不排在主列表前。搜索作用于当前页签；页签支持左右方向键及 Home / End，切换时清除批量选择。主列表为 48px 紧凑行，数量、单行时间和固定操作列对齐，长名称省略并提供完整提示。批量操作仅在有选择时出现；页签、操作栏与表头随滚动保持可见。重复建议与别名分别使用无卡片外框的分列布局，空内容和无搜索结果有独立提示。

管理页的重命名、合并、删除、固定、排序、撤销和可能重复建议保留；可能重复仅为手工整理建议，不参与新分析赋值。重复组按精确键、译名和较长子串归并，每组最多 5 个，合并前说明影响的文章数并再次确认。已经不能撤销的旧别名不再显示撤销。标签表与 API 的原有固定顺序及 `sidebar` / `sidebar_tags` 字段继续兼容，界面不再用这些字段渲染标签导航。

## 阅读器

文章页左栏只有一行栏头：左侧“← 资料库”，右侧折叠按钮，隐藏品牌行；下面目录基于正文 h2 / h3 生成；当前章节随滚动高亮，点击后标题保持在 48px 栏头下方。程序聚焦 main 不显示整栏焦点框，交互控件仍保留键盘焦点环。正文使用宋体 17px / 1.75、最大宽 612px；主标题为宋体 28px，封面 96×128px。章节时间码去除 ▶，保留等宽数字。封面过渡继续使用原有 view transition。

文章栏头与左栏返回按钮统一为 32px 高、16px 图标。上一篇 / 下一篇、本地视频和返回资料库使用图标与文字垂直居中的布局，图文间距为 4px；本地视频链接使用与相邻按钮一致的文字样式。

文章的固定章节标题在 Web 显示时转换为 Summary、Key Takeaways、Chapters、Quick Reference · 类型、Next Steps 和 Sources；八种内容类型分别显示 Tutorial、Explanation、Opinion、Recommendations、News & Events、Case Study、List、Other。已有 Markdown、正文内容、自定义标题、代码示例和存储字段保留原文，目录从转换后的标题生成。完整逐字稿和关键帧分别使用 Transcript、Video Snapshots，稿件来源、段数及图片数量使用简洁英文辅助文字。

固定章节标题采用 Inter 600、20px / 28px 和 -.01em 字距，目录为 Inter 13px / 20px。Transcript 和 Video Snapshots 为连续的两行折叠入口，采用 Inter 500、16px / 24px；闭合行高 56px，相邻入口共用分隔线，没有额外间距。标题与正文左边缘一致，12px / 20px 常规字重的来源及数量说明靠右，最右侧 16px 箭头指示开合。展开后的逐字稿和图片位于各自入口下方。正文和文章主标题继续使用阅读字体。

文章操作集中在栏头：上一篇 / 下一篇按当前筛选排序，收藏、原作品与更多菜单保留读写限制。更多菜单提供重新分析、复制文章链接和删除；信息面板不重复封面 / 标题，可复制来源文件路径。顶部 2px 进度条随中栏滚动更新。

视频正文的 Sources 章节之前增加「Transcript」原生折叠区，首次打开文章时默认折叠，显示稿件来源及段数；展开后显示全部段落的起止时间和文字。优先使用已保存的校正稿，没有校正稿时使用原始识别稿；空稿显示暂无可用逐字稿。逐字稿按纯文本渲染，保留换行；同一文章刷新保留展开状态，引用定位到折叠区内文字时自动展开。图文与没有数据库记录的只读 Markdown 不增加该区。

粗略识别窗口显示「约 起点–终点（时间未经精确对齐）」；章节涉及粗略来源时也显示范围，正文保留时间提示，不能以一个窗口起点暗示句子精确定位。没有精度记录的旧资料不重新声明为精确对齐。

同一区域增加默认折叠的「Video Snapshots」，显示有效图片数量与长期保留状态。同一文章刷新保持展开状态，缩略图按时间排序、懒加载，点图打开大图；视频仍可用时，时间链接打开对应位置。画廊使用现有样式令牌，图片完整显示。没有有效图片时说明暂无可用关键帧；不能显示其他作品图片、已清理路径或无法验证的精确时间。

资料库工具栏增加关键词 / 语义选择，默认关键词；语义有查询词时默认按相关度排序，列表和专辑墙均显示命中证据。查询方式写入 URL 的 `search_mode`，作者、标签、类型、来源、最近 / 收藏 / 灵感与批次范围在服务端排名前应用。模型不可用时显示关键词降级提示，只读 Markdown 的覆盖限制明确可见。查询词、方式或范围变化后，旧成功响应和错误均不得覆盖当前结果；失败后允许重新加载。

本地视频仍存在且属于该条资料时，栏头增加「本地视频」，信息栏显示可打开的完整 URL，不单独提供「复制 URL」按钮；文件已清理或不存在时显示不可用。视频链接为 `/api/articles/{entry_id}/video`，按当前页面来源生成完整本机地址，支持 GET、HEAD 和 Range；读取范围只限该条资料的 assets 目录，不扩展现有图片 `/media/` 接口。逐字稿与视频链接只在文章详情请求中读取，不增加资料库列表负载。

段落导航按文档顺序遍历标题、段落、嵌套列表项、引用、表格和代码；引用 / 表格 / 代码内部不重复停留。点击正文或按 `j/k/↑/↓` 移动墨绿竖条；`n/p` 切换相邻资料，`u/Esc` 返回列表并恢复滚动与焦点。控件、输入框、弹窗和菜单优先处理自己的按键。

`Shift+I` 打开信息，`Shift+N` 打开灵感并添加，`Shift+O` 打开原作品。灵感保留逐字文字、原句和时间范围，点击可定位正文并高亮；只读资料隐藏添加入口。保存后保留阅读滚动和焦点块。页面切换会断开目录观察器，过时的文章响应不能重新打开已离开的页面。

## 已停用的模型功能

页面不提供 AI 聊天、会话或消息操作、模型设置页、专题自动生成按钮、Shift+C 对话快捷键。信息、灵感及专题来源仍使用原右栏开合和焦点，保留阅读定位与高亮。

`/settings/model` 不再显示设置页，打开后是「页面不存在」；校正和分析由外部 Agent 完成。`/settings/analysis` 只说明外部 Agent 状态。旧模型 HTTP 路径直接 `410`，完整清单见[README](../README.md#web-界面)。静态文件 `model-settings.js` 仍保留，页面不再加载它。

## 操作页面

栏头路径导航的链接、分隔符和当前标题统一使用 14px / 20px，链接使用 32px 高的居中布局。导入内容页的「最近导入」为次级分区标题，使用 14px / 20px、中等字重。

导入内容是侧栏一级页面，栏头只显示「导入内容」。正文采用靠左、最大 720px 的内容列，左边缘与栏头对齐，顶部留 24px；Agent 引导标题为 16px / 24px，说明与指令为 UI 字体 13px / 20px，指令完整换行。四类指令按用途、指令、复制按钮三列排列，每行至少 48px。记录入口与最近导入用 24px 分区间距和单条细线分隔；最近导入按标题、状态、时间三列对齐，每行至少 48px，时间保持单行。单条旧入口沿用同一标题、指令字体与内容列。

导入中心用一句「去 Agent 里导入」和可复制的示例指令代替新建表单。博主、收藏、合集入口只在已有记录时出现。单条旧路径同样是可复制指令，没有新建表单、导入菜单、Cmd+I 或粘贴导航；不创建任务的分类 API 保留。没有选中记录时，收藏、博主和合集页收起选择、确认和危险操作。博主记录采用 56px 紧凑行，名称、作品数和同步时间分列对齐；未选择批次时不显示清点状态占位。选择具体批次后才显示清点状态与作品操作区，分区标题统一为 14px / 20px，选中批次栏不使用卡片外框。博主与收藏清单使用 16px 复选框和紧凑行，底部显示整个清单的已选数量；Shift 点击一次提交当页范围内的可选作品，`j/k` 移动、`x` 勾选，刷新后恢复焦点。不支持的作品、已入库限制、清单不完整的接受条件沿用原有 API。

收藏清单的新发现作品默认不勾选，增量更新沿用明确的手动选择或已经确认批次的选择；旧版无法确定来源的勾选不自动继承，历史记录保留，页面说明沿用及忽略的数量。默认只看未入库，输入后自动搜索，提供当前页、全部筛选结果和整个收藏夹的选择与取消选择。逐条和 Shift 勾选先更新本地，约 400ms 后批量保存；失败时保留选择并提供重试，确认导入等待保存完成。确认框列出件数和任务处理方式，超过 30 件需输入件数，回车仅在件数匹配时确认，否则显示校验提示；无法可靠预估的下载量和总用时明确标明。标题最多两行，话题独立显示，状态靠右并提供已入库资料入口。收藏范围在 MCP 新建时确定，页面保留已有目录与作品筛选、授权状态和危险操作。确认栏保持粘性定位。

收藏批次按读取、选择、导入、取消展示状态；读取显示已读件数和实际耗时，使用不定进度条，导入显示真实进度。取消后未导入的作品标明已取消，不重复显示单纯取消错误；已入库、失败及其他批次继续处理的真实状态保留。收藏页和任务详情提供返回清单及本批资料库入口，资料库用可移除的「本批收藏」筛选保留范围，侧栏和概览仍使用全库数据，直接打开或刷新批次链接也保持全局计数。子任务每页 50 个，可筛选失败或未完成；终态不显示等待分析提示。

任务详情移除批量任务前五篇文章的快捷入口和「子任务在下方」跳转按钮，通过下方完整子任务列表查看处理记录；单条任务的打开资料、重试、取消等操作保留。任务详情采用无卡片外框的平面分区，主标题为 16px / 24px，子任务与提示分区标题为 14px / 20px。子任务标题、统计和筛选框放在同一栏头；列表固定 148px 状态列，后接任务名称与提示两列，文字最多显示两行，完整内容可通过悬停或进入详情查看。带提示的子任务不使用整行状态底色，仅由状态徽章和提示文字说明。

## 正文与交互契约

`rendering.py` 在 Markdown 转 HTML 前移除视频封面，保留图文的全部原图，并在解析后的 blockquote 中规范化 callout：标题只保留一份加粗的“AI 推断”，多行正文单独成段。只有标题为“与灵感的关系”、内容为空或“无”的提示会省略；普通引用、其他推断正文和代码示例保留，原 Markdown 不改写。前端不得再按首个图片段落隐藏正文图片，也不得假设 HTML 中仍含 `[!note]`。图文正文将全部原图按原顺序集中到 Original Images 章节，单张图文同样展示；图片按正文宽度完整显示，不裁切，标注序号，支持点开原图，并采用懒加载。已有 Markdown 和图片文件不改写。

已有管理路由、收藏、专题选择和任务 API 保持原有语义；新建与模型 API 按[停用清单](../README.md#web-界面)返回 `410`，旧页面路径与静态资源 URL 保留。全局支持 `⌘/Ctrl+K` 搜索、`/` 当前搜索、`[` / `]` 开合侧栏、`?` 快捷键表。页面跳转在输入框外依次按 G 和目标键，需在 1 秒内完成；命令面板和快捷键表使用「G → J」这类提示，说明先关闭面板，再依次按键。输入控件内不触发页面跳转，命令面板内使用方向键和 Enter 执行。系统重复按键不算第二次 G；超时、Esc、打开面板和切换页面都会清除待续按键状态。查看导入记录和切换主题没有独立快捷键，可从命令面板执行。
