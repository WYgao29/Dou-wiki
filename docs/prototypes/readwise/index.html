DeepSeek 多模态实测：人物识别与视觉编程不及预期

发布 2026-08-23 · 采集 08-23 17:01
多模态模型测评视觉编程

灵感

用这套测试方法重新检查自己的工作流，区分“看起来理解了”和真正能完成任务的能力。

一句话

作者通过人物识别、网页复刻和交互项目，测试 DeepSeek 的实验性多模态能力：它能描述图像，但在细节判断和视觉编程任务中，仍需要明确的约束与人工验证。

核心收获

  • 图像描述流畅，不代表模型准确理解了图像中的事实与关系。
  • 网页复刻应同时检查布局、交互和细节，不能只看第一眼的相似度。
  • 把一次大任务拆成可验证的小步骤，更容易发现模型的能力边界。

时间轴图解

01:05一、从识别到理解

用同一张图片设计不同问法，观察模型如何处理视觉证据与文字提示之间的矛盾。判断的重点是它能否说明依据，而不是答案是否听起来合理。

可靠的工作流，需要让每一步的结果都能被检查。

03:40二、网页复刻测试

从界面结构开始，再逐项核对字体、间距与可操作性。把视觉相似和功能完成分别评估，可以避免忽略实际使用中的问题。
