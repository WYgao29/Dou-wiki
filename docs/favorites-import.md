# 收藏批量导入

此功能分成清点和确认两个步骤。清点仅生成可恢复的作品清单；确认后才创建现有采集管线的子任务，执行下载、转录、分析和入库。

## MCP 创建与网页管理

Agent 调用 `scan_favorites` 创建清点任务，后台 Worker 必须运行。全部收藏使用默认参数；指定夹传 `folder_ids`，目录读取传 `directory_only=true`，允许静态图文时传 `include_images=true`。目录给出稳定 ID，不能用收藏夹名称代替；同时传实际可获得的 `gateway_context`。

`/imports/favorites` 仅显示已有记录和清单，没有更新、新建范围或重新读取按钮。Agent 创建批次后，用户可直接打开 `?job=<任务ID>` 或选择历史记录。Web 的本地授权状态和授权入口保留，只查看历史不访问抖音。

1. 默认「只看未入库」。输入标题或作者自动搜索，可切换每页 50 或 100 件；取消过滤后已入库作品提供资料链接。逐条和 Shift 连选立即生效，约 400ms 后批量保存；保存失败先重试，确认等待选择保存完成。
2. 「选择本页」只选当前页，「选择筛选结果」覆盖当前筛选的全部页，「选择这个收藏夹」覆盖该夹全部未入库作品。「选择／排除整份清单」不受页码和搜索筛选限制。
3. 「确认导入所选作品」展示件数、新建与复用任务数、已入库跳过数和 Gateway 处理方式；超过 30 件需输入件数。清单不完整时先明确接受部分清单，关闭确认框不会创建任务。
4. 读取中可停止读取，导入中可取消剩余任务。取消保留清单、选择与已入库资料；需要新批次时交给 Agent 调用 MCP，其他请求共用的采集任务继续处理。
5. 任务详情保留批次汇总、分页子任务、失败项和返回清单入口。「在资料库查看本批」显示本批已选择并入库的资料，包括去重跳过的已选资料，移除筛选后返回全库。

历史记录显示创建时间、范围、件数和状态。删除导入记录和清理缓存沿用独立确认，不删除已入库资料或抖音平台收藏。另一页面已取消或确认时显示最新状态，不提交尚未保存的选择。

清单不估算下载 GB 或剩余时间。读取阶段不知道总件数，展示已读数量和耗时；导入使用实际任务进度。全部收藏直接读作品列表，包含未分组作品，不逐个遍历收藏夹；归属信息不足时明确提示。指定多个夹取并集，以作品 ID 去重。

「新增」比较同账号、同范围的更早批次，本批首次清点冻结历史集合；后续读取和删除旧记录不改变本批新增数量。新批次识别当前账号后才继承该账号的可信选择，新发现作品仍需明确选择。换账号应由 Agent 新建批次，原批次继续保留账号变化保护。

## 读取与完整性

收藏夹目录与指定夹内作品通过登录后的抖音网页原生请求读取。收藏夹和作品 ID 从原始响应在 Python 中解析，保持长数字完整，不使用名称代替 ID。默认每页 20 件，按返回的下一页标志与游标逐页读取；目录与每个所选夹各有 500 页安全上限。

目录数量与实际作品数量可能不同。例如收藏夹显示 7 条，而列表只提供 4 条时，会保留这 4 条、提示数量不一致，并要求明确接受不完整清单。夹内分页偶尔返回空/null 列表，但游标仍推进且声明有下一页：继续寻找后页可读作品，保留不完整提示；游标循环、不推进、超过上限或后续失败时停止并保留已读内容。不会根据数量差异推断其他作品的状态。

账号信息首次出现较慢时会等待其加载；读取期间仍核对同一账号。旧批次若保存了包含年龄等邻接文字的错误账号 ID，应新建批次，不自动改写或合并历史账号记录。

## 登录与后台处理

- 收藏清点和图文采集使用专用 Playwright Profile。首次或登录过期时在 Web「设置 › 授权状态」完成抖音账号授权，或运行 `douyin-wiki auth douyin`，然后重试。账号变化会暂停原批次。
- 视频主下载路径也使用专用 Profile；能否下载以具体作品的探测结果为准。`douyin-wiki auth video` 用于准备系统浏览器 Cookie，供 yt-dlp 最后回退使用。
- 后台 Worker 必须运行。只支持 Gateway，Agent 需继续检查状态和事件，完成校正与分析；待 AI 处理、待确认及历史待复核任务不算完成。
- 新建子任务沿用默认媒体临时保留规则，选定的视频直接处理，不因时长再次确认。已入库作品跳过，进行中的采集任务复用，不覆盖已有灵感、保留策略或原任务 Gateway 上下文。
- 批次汇总通过父任务及 `favorites_context.batch_silent` 表达；Agent 仍应报告需要用户处理的等待项。失败重试只重试失败子任务；需要登录的子任务通过原任务队列或授权流程恢复。
- 清点由 Agent 按用户任务和已有授权通过 MCP 创建。没有定时同步，也不会在打开网页时自动清点或导入。

## MCP 工具

| 工具 | 用途 |
| --- | --- |
| `scan_favorites` | 创建全部收藏、指定夹或目录清点；返回中间 `job_id` |
| `list_favorites_imports` | 查看历史记录 |
| `get_favorites_import` | 查看批次、目录或分页作品 |
| `set_favorites_selection` | 保存作品或收藏夹范围内的明确选择 / 排除 |
| `confirm_favorites_import` | 使用已保存选择创建或复用采集子任务 |
| `retry_favorites_import` | 按批次状态重试读取或失败子任务 |

Agent 根据已有范围和选择直接保存、确认，不因为确认工具名称重复询问；仅在缺少必要选择或部分清单决定时补充输入。Web 件数确认属于网页交互，MCP 参数按任务与已有授权填写。

`job_id` 不代表完成。Agent 继续处理每条视频的校正与分析、图文的分析及父任务汇总；`favorites_context.batch_silent=true` 时避免逐条发送完成消息。共享等待者使用 `result.shared_capture_job_id` 读取和提交实际执行任务，不改变原通知归属。完整接续见[Gateway 指南](gateway-agents.md)。

`favorites scan / list / show / select / confirm / retry` CLI 均已停用，合法旧参数仍能识别并返回非零提示。`POST /api/favorites/imports` 返回 `410`，同路径 GET 与已有批次管理保留。

## 验证边界

自动化测试使用临时模拟数据，覆盖数据库事务、幂等派发、断点、账户变化、跨来源去重、超过 5000 条清单、MCP 创建、Web 已有批次管理、CLI 停用无副作用及离线浏览器页面行为。

2026-10-04 已在会话隔离副本上验证正式适配器：4 个收藏夹、15 个可访问视频，目录、单夹、多夹及每页 2 件的主动分页均与当次网页结果核对。“时尚”显示 7 条、实际读取 4 条，保留不完整提示。原浏览器 Profile 没有被脚本直接改写，临时副本已删除。此次真实验证仅覆盖视频元数据读取；图文、文章、下载与完整入库没有真实账号端到端结论。

网页构建与接口可能变化；原生读取函数不可确认时返回明确错误，不以空清单代替失败。默认全部收藏仍使用账号级 DOM 作品列表，包含未分组作品，其归属可能不完整。

维护者可显式选择只读验收脚本；它不实例化生产服务或任务队列，记录必须放仓库外，退出清理本次会话副本。报告的 `passed` 表示读取与 ID 对照通过，不表示带数量差异的 `complete=False` 清单变完整。

```sh
DOUYIN_WIKI_RUN_LIVE=1 uv run --no-sync python scripts/verify_favorites_api.py \
  --directory-only --page-size 2 --output-dir /tmp/douyin-favorites-verification
# 可重复 --folder-id；使用目录给出的稳定数字 ID。
DOUYIN_WIKI_RUN_LIVE=1 uv run --no-sync python scripts/verify_favorites_api.py \
  --folder-id FOLDER_ID --page-size 2 --output-dir /tmp/douyin-favorites-verification
```

测试命令：`.venv/bin/pytest -q -m 'not live'`、`.venv/bin/ruff check src tests` 和 `node --check src/douyin_wiki/webapp/static/imports-favorites.js`。离线浏览器测试需要已安装 Playwright Chromium 和允许启动测试浏览器的环境；它使用临时上下文，拦截所有网络请求，不加载个人 Profile。

完整操作页面可用 `uv run --no-sync python scripts/verify_readwise_operations.py --output-dir /tmp/douku-operations-verification` 在临时 Vault 中验收；指定输出目录避免覆盖既有截图记录，临时库随脚本退出清理。
