# MCP 自助接入入口

本目录提供与客户端无关的接入规范。外部 Agent 读取本入口后，识别自身客户端能力，将通用参数转换为客户端支持的配置，在仓库外完成配置和验收。项目不维护客户端注册表、专用适配代码或每个 Agent 的生效配置。

| 文档 | 职责 |
| --- | --- |
| [自助配置步骤](self-setup.md) | 探测、外置配置、规则加载、验证、重入与回退 |
| [接入参数与验收契约](integration-contract.md) | 路径参数、STDIO 启动模板、外部目录和结果格式 |
| [Gateway Agent 接入指南](../gateway-agents.md) | 唯一共用业务规范：全部工具、已有授权、任务持续执行和事件接续 |

先读取前两份文档，再加载 Gateway 指南。客户端字段和配置位置由接入 Agent 按本机客户端版本查明，不照搬其他客户端的格式。连接 MCP 不表示客户端会自动读取本目录、根 AGENTS.md 或服务端 instructions。

| 对象 | 规则入口 |
| --- | --- |
| 源码维护 Codex / 开发者 | [根 AGENTS.md](../../AGENTS.md)与[项目结构](../architecture.md) |
| 外部 MCP Agent | [Gateway 调用规范](../gateway-agents.md#调用边界与多客户端)及其中的工具顺序、已有授权和事件接续 |
| 用户 Vault 中的知识库文档 | 应用生成的 Vault AGENTS.md；不作为源码维护指令 |

## 文件边界

| 位置 | 内容 |
| --- | --- |
| 项目仓库 | 由 Codex 维护的源码、通用文档和参数示例；外部 Agent 只读 |
| 客户端原生用户配置目录 | MCP 注册、全部工具开放和指令加载设置；必须在仓库外 |
| 仓库外独立实例目录 | 工作文件、日志、配置备份、规则加载快照、重试状态和验收记录 |
| 仓库外 Vault | 复用已准备的 0.2.0 schema 16 新库；通过全部 MCP 工具按任务和已有授权操作 |

接入 Agent 不在仓库内创建 `.mcp.json`、`.agents/`、技能、客户端说明、脚本、日志或临时文件，也不修改源码、项目配置、测试、依赖、Git 状态或现用 `.venv`。启动命令使用仓库外独立 runtime 的 wheel 安装，工作目录在仓库外，并禁用 Python 字节码写入；不使用源码 editable 环境。只在客户端自身目录创建实际需要的文件，客户端差异记录在自己的外部记录中。

复用与当前 0.2.0 安装对应的已确认配置、schema 16 新库和已登录浏览器 Profile，开放 `tools/list` 返回的全部工具。用户提出任务后，Agent 沿用已有授权持续执行，收到 `job_id` 只是中间回执，不能因此结束任务或要求用户再发一次检查指令。当前任务内的持续执行与对话结束后的自动唤醒分别核对，后台监控不是普通采集的接入前提。

## 给接入 Agent 的指令

用户可将下面的指令交给任意具有本地配置能力的 Agent，并替换仓库路径：

```text
读取 <REPO_ROOT>/docs/agents/README.md，按其中的自助配置步骤接入抖库 MCP。
自行核对当前客户端的版本、配置格式和规则加载机制，将实际配置及所有运行文件放在仓库外。
项目源码由 Codex 维护，本 Agent 对仓库只读，不在其中安装依赖或生成任何文件。
复用已准备的 0.2.0 配置、schema 16 新库和已登录浏览器 Profile，使用独立 runtime；开放 tools/list 返回的全部 MCP 工具。
沿用已有授权完成用户任务，不重复确认已授权操作；采集返回 job_id 后继续跟进到完成（含提示）、失败、取消或确实需要用户输入。
状态查询按 Gateway 指南核对 get_job 的 schema，支持 gateway_protocol=2 时显式传 2，不用完整任务反复轮询。
终态结果交付后停止该任务的跟进，取消后不自动重试；只有需要在对话结束后继续时才复用客户端自动接续机制。
原生自动接续无需额外监控器，自建事件桥单独配置；所有相关文件放在仓库外。
完成后给出配置位置、已核实能力和实际限制，不将连接成功等同于完整流程已验证。
```

当前服务提供 51 个工具，仅移除 generate_topic_artifact；业务 CLI、Web 新建、聊天、模型配置和专题自动生成已停用。升级时退出旧 STDIO 进程并重建连接，重新读取工具及共用规则；不以旧缓存代替实际清单。旧库不自动迁移，接入 Agent 不清空旧数据或自行替换生产配置。安装前提见[README](../../README.md#本地发行包与运行安装)。

框架使用当前已有且与文档版本匹配的 MCP STDIO 服务。缺少 STDIO、本地配置或必要权限时，接入 Agent 记录缺失能力并报告；不能通过修改项目代码补足。客户端原生配置和规则加载需实际生效，目录划分及提示词不提供服务端鉴权或任务排他领取。
